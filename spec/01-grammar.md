# 01 · 词法与语法

## 1. 源文本形状

- 源文件是一串**行**。一行是**一条语句**或**一条注释**。
- **一条语句默认写在一行内**；字符串中的换行必须转义。
- **唯一例外是行为头**：以 `on … :` 结尾的行，其**动作体可以写在紧随其后、缩进更深**的行上；遇到第一行缩进不深于该行为头，即结束。空行与注释行被忽略，不参与缩进判定。

  ```puppet
  on #add click when #new.value != "":
      append #todos item={text: #new.value} ; set #new value=""
  ```

  多行写法与单行写法**完全等价**（动作体各行以 `;` 连接）。允许这一例外的原因很实际：行为体单独成行是普遍排版习惯，拒绝它只会制造一整类系统性语法错误。
- 语句之间不共享上下文；**每条语句必须自足**。
- 源文件是 UTF-8。

## 2. 注释

- **注释**：`//` 之后直到行尾。`//` **无其他含义**，因此与地址记号彻底消歧。
- **地址**：`#` 之后**紧跟标识符首字符**（字母或下划线）。`#` **不是**注释记号——`#` 后必须
  是地址或颜色；`#` 之后无标识符即报错（`SYNTAX`）。
- 实现**应该**在无法判定时报告诊断，而不是猜测。

> 历史：`#` 曾同时充当注释与地址，靠"后随空白"区分。本版起注释记号为 `//`。

## 3. 记号

| 记号 | 形式 | 说明 |
|---|---|---|
| 地址 | `#` + 标识符 | 节点的全局唯一 ID |
| 注释 | `//` 到行尾 | 行内任意位置起效；`//` 无其他含义，故与地址彻底消歧 |
| 局部引用 | 标识符 `.` 字段 | 数据项绑定（如模板行绑定） |
| 属性 | `key=value` | 空格分隔，一行内可多个 |
| 字符串 | `"…"` | 转义 `\"` 与 `\\` |
| 数字 | 整数或小数 | 前导 `-` 表示负数 |
| 布尔 | `true` / `false` | 小写 |
| 颜色 | `#` + 6/8 位十六进制 | 与地址按**长度**消歧。**不采用 3 位简写**：它会与 `#bad` / `#dad` / `#abc` 这类短地址撞车 |
| 列表 | `[a, b, c]` | — |
| 字典 | `{k: v, …}` | — |
| 动作分隔 | `;` | 仅用于 `on` 的动作序列 |
| 绑定关键字 | `as` | 数据项绑定，仅此用途 |
| 参数名 | `item=` | 数据操作参数，仅此用途 |

**标识符**：首字符为字母或下划线，后续为字母、数字、下划线。

**地址必须全局唯一**。重复即**错误**（`ID_DUP`），带精确行号。

## 4. 表达式

表达式**只**出现在以下位置：属性值、`when` 守卫、动作参数、`data` 初值、字典/列表字面量内部。

**允许**：

- 字面量；
- 引用：地址属性 `#id.prop`、局部绑定字段 `t.field`；
- 算术 `+ - * /`；
- 比较 `== != < <= > >=`；
- 逻辑 `and or not`（操作数必须为布尔，不隐式取值）；
- 函数调用：`name(arg, …)`；
- 列表与字典字面量。

**禁止**：循环、自定义函数、条件分支表达式、赋值、变量声明。

**隐式类型转换**（白名单，其余组合**错误**，不猜测）：

- 数字与字符串相加 → 字符串拼接；
- 布尔转字符串 → `"true"` / `"false"`；
- 颜色转字符串 → 颜色字面量的源文本。

**内置函数**：函数集由 `04-vocabulary.md` 定义并**可扩充**（属兼容改动）。计数函数 `count(source)` 是普通函数，不再限定于数据源。

## 5. 命令的形状

```
<动词> <必需位置参数…> [属性=值…] [修饰符…]
```

- 位置参数的定义由各动词给出。
- 属性顺序无意义。
- 未识别属性名 → **警告**（`UNKNOWN_ATTR`），带行号与近似建议；**不得静默丢弃**。
- 未识别控件类型 → **警告**（`UNKNOWN_TYPE`）；**不得**渲染成空白。

## 6. 属性与值

- **值类属性**（文本、初始值、提示、工具提示等）**可以**写表达式；表达式的求值见 `03-semantics.md` 第 2 节（活绑定）。
- **引用类属性**（数据源、模板、绑定名、图标、选项来源等）**必须**是引用或字面量，**禁止**在渲染期持续求值的表达式。
- 哪些属性属于哪一类，由 `04-vocabulary.md` 逐个标注；未标注者**默认**为值类。
- **绑定不设额外白名单**（派生决定，已确认）：**任何值类属性**都可以写表达式；
  引用类属性一律**禁止**表达式（`REF_ATTR_EXPR`）；加白名单只会让“能不能绑”变成实现自由。

## 7. 动词

动词共 **12** 个。`template` 不是动词，是节点类型（见第 8 节）。

此外，第 7.7 节的**动作**（`append` / `remove` / `remove_where` / `update_where` / `clear` / `sort`）**也可以直接作为顶层语句**：

```
append #todos item={text: "买牛奶"}
remove_where #todos as t where t.done == true
```

理由：动作改的是**状态**，与"谁来触发"无关。写进 `on` 之下是"由事件触发"，写在顶层是"由驱动者触发"；两者语法一致、语义同一。

### 7.1 `add`

```
add <父地址> <类型> <自身地址> [属性=值…] [before|after <锚地址>]
```

- 父必须已存在；地址必须未被占用。违者**错误**（`PARENT_MISSING` / `ID_DUP`）。
- 锚地址不存在 → **错误**（`ANCHOR_MISSING`）， **禁止**静默追加到末尾。

### 7.2 `set`

```
set <地址> [属性=值…]
```

- 地址不存在 → **错误**（`TARGET_MISSING`）。
- 作用于**已绑定属性**时：**解除该属性的绑定**并写入字面量，且**必须**产生诊断（`BIND_OVERRIDDEN`）。
- 天然幂等。

### 7.3 `upsert`

```
upsert <父地址> <类型> <自身地址> [属性=值…]
```

- 显式幂等：不存在则新建，存在则更新给定属性（不解除未提及属性的绑定）。

### 7.4 `del`

```
del <地址>
```

- 地址不存在 → **警告**（`DEL_MISSING`），不中断本批。

### 7.5 `move`

```
move <地址> <新父地址> [before|after <锚地址>]
```

- 新父必须存在；自环与成环 → **错误**（`MOVE_CYCLE`）。
- 锚地址不存在 → **错误**（`ANCHOR_MISSING`）。

### 7.6 `data`

```
data <地址> [persist=true] = <初值> of {字段: 类型 [= 默认值], …}
```

- `<初值>` **必须**是列表字面量（数据源是行集合）。
- 声明生效后按 `<初值>` 播种——**装载与命令批一视同仁**（否则运行期新声明的数据源会是空的）。
  播种之后行集合是**状态**：由集合原语改变，不由初值反复重置。
- `of {…}` **必须**给出显式结构；**禁止**无结构的隐式结构。
- `persist=true` 表示该数据源的**数据项**进入状态文件的持久分区（见 `03-semantics.md` 第 5 节）。

### 7.7 `on`

```
on <地址|数据源地址> <事件> [as <绑定名>] [when <条件>]: <动作>[; <动作>…]
```

- 事件名集合由 `04-vocabulary.md` 定义；未识别事件 → **警告**（`UNKNOWN_EVENT`）。
- `when` 必须求值为布尔；非布尔 → **错误**（`WHEN_NOT_BOOL`）。
- 处理器的 `as <名>` 绑定该事件的**载荷**：`change` 是 `{value: <新值>}`；`click` 是空；槽事件是 `{status, value}`；数据源的 `change` 是 `{source}`。
- **行上下文与事件载荷互不相干**：行上下文的绑定名来自**模板声明的** `as`（见第 8.1 节），不是处理器的 `as`。两者可以同时出现在同一个表达式里。
- 目标静态 `disabled=true` 且绑定了交互事件 → **警告**（`DISABLED_HANDLER`）。
- 控件的**主交互事件**（见 `04-vocabulary.md` 第 5.1 节）没有任何处理器 → **警告**（`UNCOVERED_INTERACTION`）。这是"杜绝静默失败"在界面侧的直接要求：用户点了没反应，必须被说出来。
- **失败路径同受此约束**：处理器动作里的 `call`，其 `error` / `timeout` 既没有处理器也没有被订阅 → **警告**（`UNCOVERED_FAILURE`）。与上一条**同源**：判据都是"**用户操作了，而界面上不会发生任何可感知的变化**"——那条管"点了没人接"，这条管"点了、但调用失败而没人接"。不能只靠 `SLOT_TIMEOUT` 一类诊断：那些进的是**观察流**，是驾驶舱的通道，**造出来的 app 的使用者看不到**。
- **顶层 `call` 不在其列**：写在顶层的调用是**由驱动者触发**的动作，它的失败诊断进观察流、驱动者看得到，不构成"界面静默"。
- **绑定可叠加**：处理器声明的 `as t` 与动作内部声明的 `as r`（`remove_where` / `update_where`）在同一个表达式里**同时可见**，内层**不**覆盖外层。例：`on #del click as t: remove_where #todos as r where r.text == t.text`。

### 7.8 `listen`

```
listen <地址> <事件>
```

- 表示"把该事件回推给外部驱动者"。
- **不区分模式**：无论运行时是否带 LLM，语法与语义一致。没有驱动者连接时，事件进入观察流但不产生额外降级。
- **观察独立于反应**：被订阅的事件进入观察流，**与有没有处理器无关**。单纯"看"不需要先"做"。
- 只有被订阅的 `(地址, 事件)` 才推送；其余事件不进观察流。
- 事件的载荷是 `{目标地址, 事件名}`；**行内事件另带行序号**。
- 目标不存在 → **错误**（`TARGET_MISSING`）；事件名未识别 → **警告**（`UNKNOWN_EVENT`）。
- 禁用节点上的交互**不产生事件**——它根本没有被触发（见 `03-semantics.md` 第 3.4 节）。

### 7.9 `call`

```
call <函数名> with {参数: 值, …} into <地址>
```

- `into` 指向的地址**必须**是数据源（槽契约见 `03-semantics.md` 第 4 节）。
- 参数必须与函数契约匹配；缺失必需参数或类型不符 → **错误**（`CALL_CONTRACT`）。
- 目标函数不存在 → **错误**（`CALL_UNKNOWN`），**不得**静默返回空值。

### 7.10 探针

```
tree [<地址>]
get  <地址>
where <地址>
```

- 探针是**只读查询**，不改变程序或状态。
- **输出进入观察流**的 `probes` 通道（自上次请求以来），形状 `{verb, target, result}`。
- **位置决定时机**：写在**源文件**里的探针在**装载完成后**执行（此时程序已完整）；写在**批次**里的探针立即执行。
- `tree` / `get` 的目标不存在 → **错误**（`TARGET_MISSING`），且 `result` 为 `null`——不得静默返回空结构。
- `where` 依赖渲染器提供几何信息。不可用时**必须**产生 `DEGRADED_FEATURE`（信息级）并把 `result.geometry` 记为 `null`：降级必须可见，驱动者据此改走视觉自检。
- "有没有消费者"只有**宿主**知道，因此"探针的输出当前无人消费"这一提示由**宿主**（运行 app 的软件）发出，而不是由语言实现发出。
- **语言实现不发编译期警告**（派生决定，已确认）：编译期无从知道有没有驱动者连接；
  探针是无副作用的只读查询，“无人消费”不构成失败，因此没有需要升级的语义。

## 8. 模板（节点类型）

模板是**一等节点**：有地址、住节点表、有自己的子节点。

```
add <父地址> template <模板地址> as <绑定名>
add <模板地址> <类型> <子地址> [属性=值…]
set <列表地址> source=<数据源地址> template=<模板地址>
```

- 模板的 `as <绑定名>` 声明该模板内各行的**数据项绑定名**（与 `on … as` 同一套绑定语义）。
- 模板的子节点是普通节点，受**同一套**校验与诊断规则约束；不存在"模板专用的节点表"。
- 列表渲染：每行实例化一次模板子树，行内**值类属性**按行求值（见 `03-semantics.md` 第 2 节）。
- 模板未绑定到任何列表 → **警告**（`TEMPLATE_UNUSED`）。

### 8.1 行内事件的上下文

行内节点的交互事件**必须携带行上下文**——即"这是第几行"：

```
on #del click as t: remove_where #todos as r where r.text == t.text
```

- 派发者（渲染器或驱动者）**必须**给出行序号；只有它知道用户点的是哪一行。
- 引擎在派发时把**该模板声明的绑定名**（`as <名>`）指向该行记录。它与处理器自己的 `as` **互不相干**——后者绑定的是事件载荷（见第 7.7 节）。
- 无法确定行上下文（目标不在模板内、行序号越界、模板未被任何列表使用）→ **错误** `ROW_CONTEXT`，**禁止**静默地按"无绑定"派发。

## 9. 状态与状态外观

- **状态标志**（运行期属性，可读可写）：`hover` / `focus` / `pressed` / `error` / `visible` / `disabled`。读取形式 `#id.<标志>`；写入形式 `set #id <标志>=<布尔>`。
- **状态外观**：单个属性 `states`，其值为字典：状态名 → 外观属性表。

```
add #root col #card pad=16 states={hover: {bgcolor: "#f8fafc"}, error: {border: "1 #dc2626"}}
```

- `states` 中**禁止**出现布局类属性（`pad` / `margin` / `gap` / `flex` / `w` / `h` / `x` / `y` / `scroll` / `justify` / `wrap`）→ **警告**（`STATE_LAYOUT_ATTR`）。
- `states` 中**禁止**出现非外观属性 → **警告**（`STATE_UNKNOWN_ATTR`）。
- 状态外观**不触发事件、不改写程序**。

## 10. 动画

- `animate=<属性名>[ <属性名>…]` 声明对该节点哪些属性做过渡；`duration=<毫秒>`（默认 200），`curve=<缓动名>`（默认 `ease_out`）。
- 可动画属性按**语义**定义（值、位置、尺寸、透明度、颜色）。`animate` 中出现非语义可动画属性 → **警告**（`ANIMATE_UNKNOWN`）。
- 渲染器**可以**不支持其中某些属性，但**必须**在能力声明中列出并在缺失时产生可见降级说明。

## 11. 示例

```puppet
add #root window #win title="待办" w=420 h=640
add #win col #main pad=16 gap=12
add #main row #entry gap=8
add #entry input #new placeholder="添加一项…" flex=1
add #entry button #add text="添加"
add #main list #items flex=1 source=#todos template=#tpl
add #main text #count text="共 " + str(count(#todos)) + " 条"
add #root template #tpl as t
add #tpl row #row gap=8
add #row checkbox #done value=t.done
add #row text #label text=t.text flex=1

data #todos persist=true = [] of {text: str, done: bool = false}

on #add click when #new.value != "":
    append #todos item={text: #new.value} ; set #new value=""
on #done change as t:
    update_where #todos as r set done=#done.value where r.text == t.text
```

注意最后两行：`text="共 " + str(count(#todos)) + " 条"` 与 `text=t.text` 是**活绑定**（见 `03-semantics.md` 第 2 节），随数据源变化自动重算——不再需要手写 `on #todos change: set …`。
